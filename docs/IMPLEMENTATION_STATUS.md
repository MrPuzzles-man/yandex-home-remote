# Статус реализации

## Definition of Done первой итерации

- [x] Проект устанавливается и компилируется.
- [x] Backend запускается без внешних интеграций.
- [x] Есть официальный Yandex IoT user client.
- [x] Каталог нормализуется и кешируется в SQLite.
- [x] Owner может открыть динамическое Telegram-меню.
- [x] Каждая команда повторно валидирует пользователя, target, capability и value.
- [x] Callback нельзя использовать другим пользователем или повторно после потребления/TTL.
- [x] Команды одному target сериализуются.
- [x] Есть автоматические негативные тесты.
- [x] Docker image и Compose-конфигурация добавлены.
- [x] Живой API проверен с токеном пользователя: 1 Станция, 4 сценария.
- [x] Telegram long polling проверен на реальном боте.
- [ ] Команда проверена на реальном устройстве — намеренно не запускалась без явного выбора пользователя.
- [ ] YandexStation проверена через Home Assistant — Home Assistant ещё не настроен.

## Evidence boundary

Компиляция и локальные тесты подтверждают поведение нашего кода. Они не подтверждают, что конкретные устройства Яндекса возвращают ожидаемые capability или что YandexStation принимает музыкальные команды. Эти пункты остаются внешней проверкой этапа 0.
